# BGE-M3

Embeddings for [BAAI/bge-m3](https://huggingface.co/BAAI/bge-m3), MIT. The report is Chen et al., [arXiv:2402.03216](https://arxiv.org/abs/2402.03216). Papers for this pipeline are in [references.md](references.md). The listener and the write set are [../../ARCHITECTURE.md](../../ARCHITECTURE.md).

`favlo --bge-m3 quantize --src <checkout>` reads that directory and writes `models/bge-m3-int8`. The checkout is the publisher repository: `pytorch_model.bin`, `colbert_linear.pt`, `sparse_linear.pt`, and `tokenizer.json`. Quantize is the only command that opens the checkout. The row stores that directory. `embed` loads the record.

The packed record is one int8 weight image on the GPU. Each projection is symmetric int8 with one float32 scale per output channel, the peak divided by 127. The activation row that enters a projection is quantized the same way. The product is int8 times int8 with an int32 accumulator, then the two scales and the float16 bias. Word and position rows, the type row, LayerNorm, and biases stay float16. One sequence argument covers every length up to 4096, padded to a multiple of 64. The same tokens in a longer pad must match with a minimum cosine of 0.999. Quantize measures cosine against the float32 encoder on the 128 passages and keeps the record when the minimum is at least 0.96. An input longer than the served window is an error. The tokenizer and the pad live on the host. The dense vector is the L2 norm of hidden row 0, the `<s>` token. Position ids start at 2. `quantize` is the command that imports torch. That library is not a Favlo dependency. The Neural Engine window above 512 is [failed/failed.md](failed/failed.md).

`favlo --bge-m3 embed --text <sentence>` prints the 1024 floats. A missing record is an error. The command does not quantize. A warm encode of that record is [research/recorded-encode.md](research/recorded-encode.md).

`POST /v1/embeddings` takes `model` and one string `input`. The body is one embedding object and `usage.prompt_tokens`. A pipeline that defines `handle_embed` is omitted from `GET /v1/models`. An embeddings request waits until the open chat completion returns. It sits ahead of a chat that has not started, and it preempts media. A chat that has not started waits while an embeddings request is queued or running.

`uv run pytest tests/test_bge_m3.py tests/test_bge_m3_smoke.py` runs the host math. The smoke skips when `models/bge-m3-int8` is absent. `python -m harness.embeddings_agent` posts several sentences to the route on `127.0.0.1:8129` and checks that paraphrase cosines exceed cross-topic cosines.
