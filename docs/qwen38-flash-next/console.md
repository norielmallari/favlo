# Console

As-built status row for Qwen3.8-Flash-Next. Scope is in [ARCHITECTURE.md](../../ARCHITECTURE.md). If this note disagrees with that file, ARCHITECTURE.md wins.

`src/favlo/console.py` owns the row. It does not import a pipeline. A handle is a `Progress` value: phase, done, total, unit, and an optional gauge. The request thread writes those integers. A daemon thread samples them at 10 Hz. Registration takes a lock. The sample does not.

Phases are `load`, `download`, `quantize`, `prefill`, `decode`, and `sample`. Units are `tok`, `layers`, `bytes`, `shards`, `experts`, and `stages`. `--console` is `auto`, `pretty`, `plain`, or `json`. `auto` is pretty on a terminal. A pipe, `NO_COLOR`, or `TERM=dumb` selects plain. Plain prints the harness lines unchanged, plus one `favlo 0.2.0` line at startup. Pretty draws the Ingot Plate once, then one row per open handle, and prints the summary when the handle ends. A load phase begins in pretty and in JSON. Plain prints the loading line. JSON is NDJSON. Each object has `v` 1, `pipeline` `qwen38-flash-next`, and enough fields to stand alone. A tick's `eta` stays null until the 5-second rate window has at least 500 ms of samples.

Prefill `done` is `(layers completed + the fraction of the current layer) / layers`, multiplied by the incoming token count. It does not move backward. The live prefill tok/s is the tokens completed divided by the time since prefill started. A sample that adds no tokens lowers that average. The pretty row paints an exponential smooth of that rate, the ETA, and the gauge. The summary line and a JSON tick keep the raw ratio. A cached prompt that prefills nothing prints `cache hit` and the token count. It does not print a prefill rate and does not open a bar. A failure clears the live rows before the traceback is written, so the next tick does not paint over that text. `serve` in pretty mode keeps one decode row for the open request, with the request id. The row closes when that request ends, including when the client drops the stream. A later prefill closes a row the request left open. The decode row counts tokens and has no bar. `complete` and `bf16` do not draw that row. Pretty mode ends those commands with one summary line.

`favlo serve` is a process command. It does not take a model flag. The process listens before any record is loaded. A request names a folder or an alias in `models/registry.json`. A pipeline name names a row when exactly one registered record uses that pipeline. The same pipeline and the same folder stay resident. A different folder or a different pipeline closes the runtime and loads the new one. `GET /v1/models` lists every registered row: the folder, the alias, and both variants. An empty registry lists no models. `:thinking` and `:instruct` change sampling for that call. They do not load a second record. `serve` does not register a record it finds on disk.

The usage object carries `timings.prompt_per_second`, `timings.predicted_per_second`, `timings.prompt_n`, and `timings.predicted_n`. `prompt_n` is the prompt length minus the cached prefix. `prompt_tokens` remains the full prompt. The prefill clock starts at the uncached forward and ends when the first output token is sampled. The decode clock starts at that same sample and ends at the last sample. A zero duration writes a rate of 0.

`complete` and `bf16` take `--model` as a folder or an alias. `--record` is still a direct path and wins when it is set. `quantize --alias` stores the alias on the directory it writes. The derived directory name is `{source name}-` plus each quant in the map, wider first: `fp8`, `fp4`, or `int2`.
