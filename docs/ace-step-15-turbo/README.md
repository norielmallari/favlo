# ACE-Step 1.5 XL Turbo

Stereo music from a caption and optional lyrics. The official base model is [ACE-Step/acestep-v15-xl-turbo](https://huggingface.co/ACE-Step/acestep-v15-xl-turbo). Favlo reads the Diffusers split [ACE-Step/acestep-v15-xl-turbo-diffusers](https://huggingface.co/ACE-Step/acestep-v15-xl-turbo-diffusers) and serves the packed directory `acestep-v15-xl-turbo-fp8-fp4`. Both checkpoints are under the MIT License. `favlo --ace-step-15-turbo` loads `pipelines/metal41/ace-step-15-turbo.py`. Device spans come from the process memory manager. `open_runtime` takes `owner` and `max_memory`. Every span from that opening uses the owner, and `close` sweeps it. An omitted owner is minted from this runtime's id. A diffusion step returns the activations it does not keep, so the live scratch is one step. The decoder does the same, in one-second tiles. Each tile carries the latent neighborhood that second reads, which is the receptive field of the convolution stack, so the sample matches a full-length decode. A residual holds the skip and the branch being written, which is three buffers at that tile's widest length. The reservation is the larger of that tile and one diffusion step. The duration stays the request. An omitted duration is 30 seconds. A ledger that cannot hold the weights, or that reservation, raises before the draw.

```text
uv run favlo --ace-step-15-turbo setup
uv run favlo --ace-step-15-turbo quantize
uv run favlo --ace-step-15-turbo delete acestep-v15-xl-turbo-fp8-fp4
uv run favlo --ace-step-15-turbo kernels
uv run favlo --ace-step-15-turbo generate --prompt "anime opening, J-pop, electric guitar, synth lead, electric bass, punchy drums, uplifting, playful, bright, polished, catchy hook" --lyrics "[Intro - electric guitar]

[Hook - synth lead]" --bpm 168 --keyscale "D major" --timesignature 4/4 --seconds 10 --out clip.wav
```

Download, pack, and the first clip are [SETUP.md](SETUP.md). `setup` downloads the Diffusers repository into `models/acestep-v15-xl-turbo`. It does not read `silence_latent.pt`. `quantize` packs linear and convolution weights as fp8 E4M3 with an E8M0 scale byte per 32 values along K. The DiT MLP is the exception. Each of the 32 layers is scored by the RMS of its BF16 matrix against the restored fp4 matrix, divided by the source RMS. Gate, up, and down share the worst of those three scores. The largest whole count that does not exceed 20% of 32 is 6, so those six layers are stored as fp8 and the other 26 stay fp4. An equal score keeps the lower layer index. The chosen layers are `mlp_error.json`, and the manifest records `mlp_fp8_percent` and `mlp_fp8_layers`. The scores are [research/dit-mlp-fp4-error.md](research/dit-mlp-fp4-error.md). Norms, biases, AdaLN tables, Snake parameters, and the silence latent stay float32 on device. Attention keys and values are fp8 E4M3 with an E8M0 scale per 32 values. Queries, the latent, and the waveform stay float32. Activations are float16 only at the matmul operand.

The turbo schedule is 8 Euler steps at shift 3. Classifier-free guidance is not run. A request `steps` value other than 8, or a `cfg_scale` other than 1, is rejected. Duration is 10 seconds through 10 minutes. The latent rate is 25 Hz. A 10 second clip is 250 frames and 125 tokens after the kernel-2 patch.

`generate_music` on `POST /mcp` holds the request lock and returns an `audio.music` job before generation finishes. A path under `/v1/audio` is 404. `resources/read` of `favlo://music/{id}.mp3`, `favlo://music/{id}.wav`, or `favlo://music/{id}.flac` does not take that lock. The suffix is the job's response format. It returns that file and does not encode a different one. OpenAI has no music-generation route. Spoken voice is not this tool. The job object follows the Videos job Favlo already serves. The body also accepts the Stability text-to-audio field names: `duration` (wins over `seconds` when both are present), `output_format` (`mp3`, `wav`, or `flac`), `seed`, `steps`, and `cfg_scale`. `response_format` is the OpenAI speech name for the same format list. The default format is `mp3`. The WAV is 48 kHz stereo 16-bit PCM. The MP3 is 256 kbps. The FLAC is lossless. The waveform is peak-normalized to −1 dBFS after the decoder tiles are joined, before the WAV is written. A chat that arrives while this clip holds the GPU sets `state["preempt"]`. Cancel of the running task sets `state["cancel"]`. `halt` is the same stop, used when the listener receives a signal. Both are `threading.Event`s. `generate` finishes the Metal dispatch already submitted, then stops. The boundaries are before the first shader, after the text tower, after the lyric encoder, after the timbre encoder, after each Euler step, after the waveform is read, and before the file is stored. The device is closed at that boundary and opened again on resume. `reached` is stage order: a later stage has finished every earlier one, and a finished stage whose array is missing is an error. The text, lyric, and timbre arrays, the noise latent, and the waveform stay on `state["music_hold"]` with the same job id. The listener runs the waiting chats and calls `handle_music` again with the same body. That call keeps the id and does not rerun a stage that has been reached. The cross-attention cache is built again from those arrays. The source and the mask are built again from the silence latent. Cancel leaves the job `in_progress` and does not keep the hold. The listener deletes a stored WAV for that id.

`python -m harness.music_smoke_agent` generates the 10 second clip in `docs/ace-step-15-turbo/smoke.json`, then `harness/inspect_wav.py` writes the report and the spectrogram. The report includes the key, the half-second pitch, and the half-second harmony. The smoke compares the request template (`seconds`, `key`, `bpm`) with the same three fields in that report. That run is not part of `pytest`. `python -m harness.music_long_agent` generates the 3 minute clip in `docs/ace-step-15-turbo/long.json` the same way, into `artifacts/music-long-agent.wav`. Exit 0 also requires a settled key margin, a tonal spectrum, few quiet slices, and one-second joins no louder than the samples beside them. That run is not part of `pytest`.

The text encoder is the checkpoint's Qwen3 model: 28 full-attention layers, hidden 1024. Lyric tokens use that embedding table and then the 8-layer lyric encoder. The timbre encoder runs on the first 750 frames of the baked silence latent and pools index 0. `timbre_encoder.special_token` is stored in the checkpoint and is not added on this path. The condition order is lyric, then the pooled timbre vector, then text. The DiT is 32 layers, hidden 2560, sliding attention on layers where the one-based index is odd, window 128, not causal. Cross-attention has no RoPE and no mask. The Oobleck decoder is five upsample stages with ratios 10, 6, 4, 4, and 2, and three dilated residual units (dilations 1, 3, and 9) after each upsample. Each consumed activation is freed before the next allocation. The decode walks the latent in one-second tiles. A tile includes every latent frame that second's samples read, and the waveform is peak-normalized after the tiles are joined. The VAE encoder is not loaded.

## References

The schedule, the condition strings, and the module list follow the Diffusers ACE-Step pipeline and the checkpoint configs. The flow-matching Euler step is `x ← x + (t_next − t) v`. Snake alpha and beta are log-space. The decoder uses `y = x + sin(exp(alpha) * x)^2 / exp(beta)`. When a Snake block stores only `alpha`, that vector is also `beta`. The text tower is causal. Lyric and timbre attention are not. The job object follows the video job Favlo already serves. The field names `duration`, `output_format`, `seed`, `steps`, and `cfg_scale` follow Stability AI text-to-audio (`POST /v2beta/audio/stable-audio/text-to-audio`). The published ACE-Step duration range replaces Stability's 1–380 second range.
