# ZONOS2

As-built note for the `zonos2` pipeline. The process contract is [../../ARCHITECTURE.md](../../ARCHITECTURE.md). This directory wins for this pipeline's records and kernels. Another pipeline does not edit it.

The model card is [Zyphra/ZONOS2](https://huggingface.co/Zyphra/ZONOS2). The report is Clark et al., [arXiv:2606.24320](https://arxiv.org/abs/2606.24320). Papers for the kernels are [references.md](references.md). Device spans come from the process memory manager.

`kernels`, `inspect`, `quantize`, and `generate` require `favlo --zonos2`. That flag loads `pipelines/metal41/zonos2.py`, which loads `zonos2`. The package does not import another pipeline.

```text
uv run favlo --zonos2 kernels
uv run favlo --zonos2 inspect --src <checkout>
```

`kernels` compiles the shader libraries at Metal 4.1. It checks RMSNorm, adjacent-pair RoPE, SwiGLU, the logit softcap, fp4, fp8, and half `matmul2d`, grouped-query attention, and the DAC conv, transposed conv, and Snake formulas. The host formulas live in `zonos2/checks.py`, `zonos2/session.py`, and `zonos2/codec.py`. A missing kernel stays missing.

`quantize --src <checkout>` reads that BF16 directory. The SSD copy is `models/ZONOS2-bf16`. It scores the 24 MoE layers, writes `ffn_error.json`, and packs `models/ZONOS2-fp8-fp4`. The prompt is the speaker projection, noisy-background token 517, accurate-mode token 518, trailing-silence bucket 3 at token 511, then BOS, each UTF-8 byte at row 192 plus that byte, and EOS. A text row is added to the nine audio-pad embeddings. An audio step adds the text-pad row. The first 17 rows of the sheared 0.2 s silence follow the text. The stack applies a parameter-free RMSNorm to the sum. Query RMSNorm uses eps 1e-6 and the absolute query scale, and it runs before RoPE. Every generated frame samples all nine codebooks. The clip ends when codebook 0 samples end-of-audio. `unshear` drops the delay. Codes above 1023 clamp to 1023. `generate --src <record> --text <sentence> --out <file.wav>` writes 44.1 kHz mono PCM from that packed record. `--speaker` is an optional 2048-float vector. When it is omitted, the speaker vector is zeros through the LDA projection and the speaker projection. The DAC decoder reads `models/dac/model.safetensors`, the published 9-codebook 44.1 kHz checkpoint. Each upsample is a transposed convolution, then three residual units with dilations 1, 3, and 9. A clip passes the speech check when its level is above the silence floor, it is not clipped, it lasts 0.75–12 s, most of its energy is from 80 Hz to 4 kHz, spectral flatness in that band sits between a tone and noise, and its pitch moves. That check is `tests/test_zonos2_smoke.py`.

`python -m harness.voice_smoke_agent` asks the instruct model to call `generate_voice` on `POST /mcp`, reads `favlo://voice/{id}`, and checks 44.1 kHz, mono, a level above the silence floor, and a duration inside 6144 frames. The sentence is [smoke.json](smoke.json). That run is not part of `pytest`.

The cached checkout's `model.pth` is 15,336,390,655 bytes and holds 507 bfloat16 tensors. Nine audio embeddings, `multi_embedder.embedders.0` through `.8`, are 1026×2048. The text embedding, `multi_embedder.embedders.9`, is 520×2048. `params.json` sets `text_vocab` to 519. Rows 0–191 are the legacy symbols, including BOS at 2 and EOS at 3. UTF-8 bytes occupy rows 192–447. Row 519 is the text pad. The nine audio heads are one matrix, `multi_output.weight`, 9234×2048. Expert gate and up are the even and odd rows of `experts.w13`, 16×6144×2048, and the down projection is `experts.w2`, 16×2048×3072. Dense layers store `w_in` as 2×3072×2048 and `w_out` as 2048×3072. The router MLP is 128×128, 128×128, then 16×128, and that last linear has no bias. Each hidden layer uses erf GELU. The router softmaxes, then adds `balancing_biases` for the top-k choice. The mixture weight stays the softmax probability. `router_states_scale` is a length-128 vector on layers 4–26 and is absent on layer 3. `balancing_biases` is present on every MoE layer. Query scale `attention.temp` is 1×16×1. Speaker LDA is 1024×2048 and the speaker projection is 2048×1024, each with a bias. The file has no DAC decoder and no ECAPA-TDNN encoder.

The packed record is `models/ZONOS2-fp8-fp4`. Expert gate, up, and down are fp4 E2M1 except four MoE layers. `promote_count(20, 24)` is 4, so those layers are fp8 E4M3. Attention, the four dense FFNs, and the audio head are float16. fp8 on those planes selects end-of-audio for the first codebook. The key/value cache is a float32 host array per layer. The scale is one round-up E8M0 byte per 32 values along K. Each fp4 or fp8 matrix has its own heap, and the data plane starts at offset zero. A blockwise tensor later in a shared heap reads zeros. Router, norm, embedding, speaker, and codec tensors stay half. The scored layers, highest first, promote 26, 21, 3, and 22.

`open_runtime` loads the packed record. A BF16 checkout, and a `bf16` cache request, are refused. `handle_chat` refuses a chat completion. `handle_voice` writes `~/.favlo/voice/<id>.wav`. `generate_voice` on `POST /mcp` is the listener tool. A pipeline that defines `handle_voice` is omitted from `GET /v1/models`.
