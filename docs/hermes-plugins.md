# Hermes plugins

As-built install of the Favlo backends for Hermes Agent. The map is [../ARCHITECTURE.md](../ARCHITECTURE.md).

`favlo hermes-plugins` copies `hermes-agent-plugins/image_gen/favlo` and `hermes-agent-plugins/video_gen/favlo` into the default Hermes home. Every directory under that home's `profiles/` folder is another profile. Each of those profiles gets a symlink for both backends, pointing at the default home's copy. Hermes discovers user backends from that profile's `plugins/` directory, and `plugins.enabled` is read from that profile's `config.yaml`. The command adds `image_gen/favlo` and `video_gen/favlo` to `plugins.enabled`. The image plugin name is `favlo_image_gen` and the video plugin name is `favlo_video_gen`. When a profile has no provider on those sections, it sets `provider: favlo_image_gen` and `provider: favlo_video_gen`. A section that still says `provider: favlo` is renamed to that backend. A platform tool list that already contains `image_gen` also gains `video_gen`. A `cli` list gains `image_gen` and `video_gen` when either name is absent.

The image backend calls `POST /v1/images/generations` on `localhost:8129`. The video backend calls `POST /v1/videos`, polls `GET /v1/videos/{id}`, and saves `GET /v1/videos/{id}/content`. Image-to-video requires `image_url`. An omitted duration stays 81 frames. `resolution` is `320p` or `240p`. 320p is 576×320, 320×576, or 512×512. 240p is 416×240, 240×416, or 256×256. Any other resolution value stays on the 320p frame. On load, the video plugin adds `320p` and `240p` to the `video_generate` resolution enum so a deferred call that passes either value is accepted. `--home` selects a Hermes home. The default is `HERMES_HOME`, or `~/.hermes`.
