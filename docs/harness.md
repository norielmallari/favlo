# Harness

As-built clients that score a running `favlo serve`. The map is [../ARCHITECTURE.md](../ARCHITECTURE.md). A pipeline's scores live in that pipeline's `benchmarks.md`. `python -m harness`, `python -m harness.coding`, and `python -m harness.worktree` take the machine lock with `python -m favlo.smoke_lock`. The recorded pid is the shell that invoked it. A lock that shell already holds stays in place. A media harness does not take that lock. It calls the listener.

`python -m harness.server status` prints `listening` or `down` for `127.0.0.1:8129`. `python -m harness.server run -- <command>` is the listener session. A process already listening there is reused and left running. A closed port starts the daemon, and the session stops that process when the command exits. A media harness calls that same session and does not bind a second port. `python -m harness`, `python -m harness.coding`, and `python -m harness.worktree` restart the process they started so a later turn reloads a prefix. Those three require the port to be free.

`python -m harness.benchmarks --model <id>` scores IFEval, GSM8K, and HumanEval against `serve`. The `model` field is that id. Thinking stays off. Omitted sampling fields are filled from `GET /v1/models` row `<id>:instruct`. A CLI flag overrides that field. The checker reads `message.content`. `--limit 30` scores the first 30 rows and writes the smoke section. `--limit 100` writes the sample of 100. A run with no limit scores the smoke, then the full sets. That run is not part of `pytest`. Each finished suite is written into `docs/<pipeline>/benchmarks.md`.

`pytest` includes the file agent: it starts `serve` and checks that create, edit, and confirm land in the workspace. `python -m harness.file_agent` is that client against an already running server.

`python -m harness --model <id>` starts `serve`, reads repository files one turn at a time until the prompt reaches the token target (default 65536), and prints the server's prefill and decode rates. The model field is the pipeline name. The request sets `enable_thinking` false and leaves every other sampling field unset, so the listener fills the instruct card. The server stops after the first turn and starts another, so the second turn loads the prefix from disk. Later turns stay on that server. That run is not part of `pytest`.

`python -m harness.coding --model <id>` starts `serve` and sets `enable_thinking` true on that same bare id. The model writes `ledger.py` through tools. A pytest file outside the workspace is the result. Exit 0 is a pass. The command prints each request's prefill and decode line. That series stays separate from the file agent's. That run is not part of `pytest`.

`python -m harness.worktree --model <id>` starts `serve` and checks out a detached worktree of `main` under `artifacts/`. The model writes `notes/span.py`, `notes/check.py`, and `notes/README.md` through tools. Write turns set `enable_thinking` true. A grader outside the worktree checks those files, and a failed check is sent back for another write. The same Microsoft Agent Framework session then reads worktree source with `enable_thinking` false until a prompt reaches 131072 tokens. The next turn runs `SummarizationStrategy` before that request is sent, and the summary call uses the instruct card. Exit 0 requires the grader, a prompt of at least 131072 tokens, and a later prompt shorter than that peak. The command prints each request's prefill and decode line. That run is not part of `pytest`.

`python -m harness.image --model <id>` calls `generate_image` on `POST /mcp`, then reads the PNG with `resources/read`. The prompt, size, and seed come from that pipeline's `smoke.json`. It uses the listener session above. Exit 0 means those bytes were read. The command does not score the picture and is not part of `pytest`.

`python -m harness.image_smoke_agent` uses `favlo serve`. A Microsoft Agent Framework agent on `qwen36-35b-a3b:instruct` calls `generate_image` on `POST /mcp` twice for `Z-Image-Turbo-fp4` with the prompt, size, and seed in `docs/z-image-turbo/smoke.json`, at `quality` `low` and then `max`. Each PNG is read with `resources/read` and written to `artifacts/image-smoke-agent-low.png` or `artifacts/image-smoke-agent-max.png`. The next turns send each PNG to the same model and ask whether the picture matches the prompt. Exit 0 means both replies affirm it and the max file is larger. That run is not part of `pytest`.

`python -m harness.image_persona` uses `favlo serve`. The agent instructions are the terminal persona. The user asks that horse to draw a picture of himself. The image prompt is a cute 2.5D horse with a white blaze and large blue eyes, sitting at a desk. The image call is `Z-Image-Turbo-fp4` at the pipeline's maximum edge, seed 0. The command prints the PNG byte count. The next turn asks whether the picture shows that stylized horse rather than a photograph. Exit 0 means the reply affirms it. The PNG is `artifacts/favlo-horse.png`. That run is not part of `pytest`.

`python -m harness.video_smoke_agent` uses `favlo serve`. A Microsoft Agent Framework agent on `qwen36-35b-a3b:instruct` draws `artifacts/video-smoke-agent.png` with `Z-Image-Turbo-fp4` when that file is missing or is not the clip size. The still sentence is `prompt` in `docs/wan22-i2v/smoke.json`. The width, height, and seed are the clip's. The next turn calls `generate_video` for the model in that file, using `video_prompt`, the smoke frame count, and the still as a PNG image block. It reads `favlo://videos/{id}` into `artifacts/video-smoke-agent.mp4`. The same model reads frame 0, the middle frame, and the last frame of that file and must affirm the still sentence. Exit 0 means each of those frames was affirmed and the file has that geometry. That run is not part of `pytest`.

`python -m harness.music_smoke_agent` uses `favlo serve`. A Microsoft Agent Framework agent on `qwen36-35b-a3b:instruct` calls `generate_music` on `POST /mcp` for the model, prompt, lyrics, seconds, seed, bpm, keyscale, and timesignature in `docs/ace-step-15-turbo/smoke.json`. It reads `favlo://music/{id}` as WAV into `artifacts/music-smoke-agent.wav`. `harness/inspect_wav.py` writes the report and `artifacts/music-smoke-agent.inspect.png`. The report adds the Krumhansl-Kessler key, the half-second pitch, the half-second harmony, a quiet-slice count, and a tempo estimate. `--keyscale`, `--bpm`, and `--reference` add the request check and the distance to a saved clip. The report ends with a `template_output` block: `seconds`, `key`, and `bpm`. The smoke prints the matching `template_input` from the same three fields in `smoke.json` and compares the two. Seconds must agree within 0.05. The key must be the same note and mode. The tempo may sit within 3% of the request, the relative just-noticeable difference for a six-interval sequence (Drake and Botte, 1993). Exit 0 means that comparison passed and the file is 10 seconds, 48 kHz, stereo, with RMS above the silence floor. The tool result is a short status. The harness compares the report. The judge does not listen to the file. That run is not part of `pytest`.

`python -m harness.video_quality_agent` uses `favlo serve`. It draws `artifacts/video-quality.png` at 416×240 with `generate_image` when that file is missing or is not that size. The still sentence is the `prompt` in `docs/wan22-i2v/smoke.json`. It then calls `generate_video` twice, at `quality` `low` and then `max`, with no chat between those tasks, and reads each `favlo://videos/{id}` into `artifacts/video-quality-low.mp4` and `artifacts/video-quality-max.mp4`. Exit 0 means both files are 5 frames at 416×240 and the max file is larger. That run is not part of `pytest`.
