# Harness

As-built clients that score a running `favlo serve`. The map is [../ARCHITECTURE.md](../ARCHITECTURE.md). A pipeline's scores live in that pipeline's `benchmarks.md`. A command that starts `serve` takes the machine lock with `python -m favlo.smoke_lock`. The recorded pid is the shell that invoked it. A lock that shell already holds stays in place.

`python -m harness.benchmarks --model <id>` scores IFEval, GSM8K, and HumanEval against `serve`. The `model` field is that id. Thinking stays off. Omitted sampling fields are filled from `GET /v1/models` row `<id>:instruct`. A CLI flag overrides that field. The checker reads `message.content`. `--limit 30` scores the first 30 rows and writes the smoke section. `--limit 100` writes the sample of 100. A run with no limit scores the smoke, then the full sets. That run is not part of `pytest`. Each finished suite is written into `docs/<pipeline>/benchmarks.md`.

`pytest` includes the file agent: it starts `serve` and checks that create, edit, and confirm land in the workspace. `python -m harness.file_agent` is that client against an already running server.

`python -m harness --model <id>` starts `serve`, reads repository files one turn at a time until the prompt reaches the token target (default 65536), and prints the server's prefill and decode rates. The model field is the pipeline name. The request sets `enable_thinking` false and leaves every other sampling field unset, so the listener fills the instruct card. The server stops after the first turn and starts another, so the second turn loads the prefix from disk. Later turns stay on that server. That run is not part of `pytest`.

`python -m harness.coding --model <id>` starts `serve` and sets `enable_thinking` true on that same bare id. The model writes `ledger.py` through tools. A pytest file outside the workspace is the result. Exit 0 is a pass. The command prints each request's prefill and decode line. That series stays separate from the file agent's. That run is not part of `pytest`.

`python -m harness.worktree --model <id>` starts `serve` and checks out a detached worktree of `main` under `artifacts/`. The model writes `notes/span.py`, `notes/check.py`, and `notes/README.md` through tools. Write turns set `enable_thinking` true. A grader outside the worktree checks those files, and a failed check is sent back for another write. The same Microsoft Agent Framework session then reads worktree source with `enable_thinking` false until a prompt reaches 131072 tokens. The next turn runs `SummarizationStrategy` before that request is sent, and the summary call uses the instruct card. Exit 0 requires the grader, a prompt of at least 131072 tokens, and a later prompt shorter than that peak. The command prints each request's prefill and decode line. That run is not part of `pytest`.

`python -m harness.image --model <id>` posts one image generation to a `favlo serve` that is already listening. The prompt, size, and seed come from that pipeline's `smoke.json`. Exit 0 means the response contains `b64_json`. The command does not score the picture and is not part of `pytest`.

`python -m harness.image_agent` holds the machine lock, then uses `favlo serve`. A Microsoft Agent Framework agent on `qwen36-35b-a3b:instruct` calls `POST /v1/images/generations` for `Z-Image-Turbo-fp4` with the prompt, size, and seed in `docs/z-image-turbo/smoke.json`. The next turn sends that PNG to the same model and asks whether the picture matches the prompt. Exit 0 means the reply affirms it. That run is not part of `pytest`.

`python -m harness.image_persona` holds the machine lock, then uses `favlo serve`. The agent instructions are the terminal persona. The user asks that horse to draw a picture of himself. The image prompt is a cute 2.5D horse with a white blaze and large blue eyes, sitting at a desk. The image call is `Z-Image-Turbo-fp4` at the pipeline's maximum edge, seed 0. The command prints `generation_seconds`. The next turn asks whether the picture shows that stylized horse rather than a photograph. Exit 0 means the reply affirms it. The PNG is `artifacts/favlo-horse.png`. That run is not part of `pytest`.

`python -m harness.video_agent` holds the machine lock, then uses `favlo serve`. A Microsoft Agent Framework agent on `qwen36-35b-a3b:instruct` draws `artifacts/video-agent.png` with `Z-Image-Turbo-fp4` when that file is missing or is not the clip size. The still sentence is `prompt` in `docs/wan22-i2v/smoke.json`. The width, height, and seed are the clip's. The next turn posts `POST /v1/videos` for the model in that file, using `video_prompt`, the smoke frame count, and the still as `input_reference`. It polls `GET /v1/videos/{id}` and saves `GET /v1/videos/{id}/content` to `artifacts/video-agent.mp4`. The same model reads frame 0 of that file and must affirm the still sentence. Exit 0 means the frame was affirmed and the file has that geometry. That run is not part of `pytest`.
